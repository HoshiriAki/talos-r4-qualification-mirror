## 一、风格定义

### 主风格：Isometric Brutalism（等角粗野主义）

这是六种参考风格中**与 Terminal Brutalist 血缘最近**的一种。它将建筑粗野主义的原始几何感与 CAD 制图/3D 建模工作台的线框美学融合，创造出一种"在工程软件中管理危机"的沉浸体验。

### 子风格特征

| 子风格 | 权重 | 表现 |
|--------|------|------|
| **建筑粗野主义** | ★★★★★ | 裸露结构、尖锐几何体（立方、平板）、"未完成"的建筑工程感 |
| **等角透视（Isometric）** | ★★★★★ | 整个中央舞台是等角 3D 建筑模型，没有传统 2D 布局 |
| **工程制图美学** | ★★★★★ | 辅助线、构造节点、浮空几何原始体（球、立方体），像 Blender/CAD 视口 |
| **工业警示语言** | ★★★★☆ | 黑黄/黑白对角警示条纹、"施工区域"的视觉编码 |
| **极限制色** | ★★★★★ | 严格的黑-白-灰，仅一种侵略性红色作为强调 |
| **零阴影深度** | ★★★★★ | 完全无投影，所有深度来自等角透视和硬黑底座 |
| **Glitch/模板文字** | ★★★☆☆ | 中文字符带有"断裂"切口或模板镂空效果，强化"受损/腐化"主题 |
| **网格覆盖层** | ★★★☆☆ | 浅灰色网格线覆盖红色背景，锚定浮空元素 |

### 整体情绪

**临床感、威权感、不祥预感。** 传达高科技官僚机构管理危机的感觉。"制图"隐喻暗示玩家/用户正在实时规划操作或分析数据。红色背景唤起警戒或紧急状态，而鲜明的黑白结构暗示严苛的秩序与控制。这是一款将**氛围感置于传统可用性约定之上**的高级、高度内聚的设计。

### 细节：顶部操作栏

**位置：** 屏幕最上方，水平条  
**背景：** 半透明/融入红底  
**左：**
- 用户头像（圆形）+ 用户名 "arom"
- 等级显示 "Lv.120"（大号、压缩、倾斜）
- 货币图标（Hypercube 等虚拟货币）

**右：** 7 个系统图标水平排列
- 设置 ⚙️
- 好友/社交
- 仓库 📦
- 邮件 ✉️
- 情报/信息 🧠
- 装备/物品 🎒
- 任务/成就 📋

**交互状态：** 图标使用黑白高对比，无边框，靠形状识别

### 细节：左侧垂直卡片栏

**位置：** 屏幕左侧，垂直堆叠  
**宽度：** ~80-100px  
**内容：** 3 个主要交互入口卡片（从上到下）
1. **"Procurement"（采购/抽卡）** — 商店/获取
2. **"Sinner"（角色管理）** — 核心玩法入口
3. **"Recruit"（招募）** — 获取新角色

**样式：**
- 白色背景 + 黑色图标/文字（或反转）
- 锐角矩形，**无圆角**
- 卡片之间紧密排列或微间距
- 可能包含小红色圆点通知 Badge

### 细节：中央等角 3D 舞台（核心）

**面积：** 占据屏幕 ~60-70%  
**类型：** 大型、精细的等角透视 3D 建筑模型  
**渲染风格：** "线框叠加实体" — 白色几何面板覆盖在黑色结构底座上

**构成元素：**

1. **建筑主体：**
   - 白色平面 + 黑色侧面的等角立方体组合
   - 多层结构，层叠而建
   - 某些区域显示"剖面"或"未完成"状态

2. **构造线（Construction Lines）：**
   - 细白/灰线从建筑节点延伸
   - 类似 CAD 软件中的辅助线
   - 水平/垂直/等角方向

3. **构造节点（Nodes）：**
   - 小球体散布在线条交叉点
   - 标记结构关键位置

4. **浮空几何原始体：**
   - 独立的立方体、球体群组
   - 悬浮在建筑周围
   - 增加建筑模型的纹理和深度
   - 无直接功能，纯视觉增强

5. **红线连接：**
   - 红色直线从右下"Mission"体力图标延伸至建筑结构
   - 可视化资源（Sanity/体力）向操作的流动

6. **章节标识：**
   - 浮在模型上方
   - "Chapter 1: Disappearance"
   - 左右导航箭头 ◀ ▶

### 细节：右下角 CTA 区域

**"Mission"（任务/行动）按钮：**
- **位置：** 右下角，锚定在等角结构上
- **样式：** 黑白对角警示条纹（"candy cane" pattern）
- **内容：** 体力数值 "90/120" + 图标
- **视觉连接：** 红色连线延伸至中央建筑
- **大小：** 相对较大，是主要操作入口

**"Base"（基地/总部）按钮：**
- **位置：** 最右下角
- **样式：** 简洁几何图标
- **角色：** 管理/建设入口

### 细节：左下角信息区

- "公告 Announcements" — 红色横线分隔
- "攻略 Strategy/Guides" — 红色横线分隔
- 文字链接样式，可能为白色文字 + 红色下划线

## 三、色彩体系

### 角色色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 背景红 | `#D63031` | 整页底色，鲑鱼红/赤陶色，警戒状态 |
| UI 白 | `#FFFFFF` | 几何面板、卡片背景、文字 |
| 结构黑 | `#000000` | 建筑底座、UI 元素、对比锚点 |
| 强调红 | `#FF0000` | 通知圆点、连线、警示元素 |
| UI 灰 | `#888888` ~ `#AAAAAA` | 网格覆盖线、次要 UI 元素 |
| 警示条纹 | 黑 `#000000` + 白 `#FFFFFF` | 对角警示带图案 |

### 色彩原则

- **极限制色：** 严格的黑、白、灰 + 红底 + 红强调。共计仅 4-5 个色值
- **红底作为"常态"：** 全局红色背景不是"错误状态"而是"日常警戒"，这是最激进的设计选择
- **黑/白二元 UI：** UI 元素仅在纯黑和纯白之间切换，无中间调
- **红色仅用于两类：** 全局背景 + 关键强调（连线、通知 Badge、分割线）
- **无渐变、无透明、无模糊：** 所有色彩是绝对的、平坦的、不透明的
- **灰色仅用于辅助线：** 网格和构造线使用唯一的中性灰

### 与 Terminal Brutalist 的色彩映射

| Terminal Brutalist | Isometric Brutalism |
|---|---|
| `--bg-base: #161618` | `#D63031`（红色） |
| `--bg-surface: #1E1E20` | `#000000`（黑色面板） |
| `--text-primary` | `#FFFFFF` |
| `--text-secondary` | `#888888` |
| `--accent` | `#FF0000` |
| 边框: 1-2px 锐利 | 无边框，靠色块分离 |

## 四、字体排版

### 字体家族

**首选：** 自定义几何无衬线体（类似 Eurostile / Microgramma Extended，但更尖锐）  
**特征：** 方正、几何感、中等宽度，为可读性使用中等到粗字重

### 字重阶梯

| 层级 | 字重 | 大小 | 用途 |
|------|------|------|------|
| L1 | Bold 800-900 | 36-48px | 体力大数字 "90/120" |
| L2 | Bold 700-800 | 28-32px | 核心操作按钮文字（"Mission" 行动） |
| L3 | Bold 600-700 | 18-22px | 章节标题、卡片标题 |
| L4 | Medium 500-600 | 14-16px | 菜单标签、用户名 |
| L5 | Medium 400-500 | 12-13px | 辅助信息、公告链接 |

### 排版原则

- **数字最大、最粗：** 体力 "90/120" 是页面上最大的文字元素
- **斜体/倾斜用于动态感：** "Lv.120" 使用压缩 + 倾斜（italic/slanted）
- **中文字符 Glitch 效果：** 文字带有模板镂空切口（stencil gaps），仿佛被"损坏"或"腐蚀"
- **全大写 + 宽间距用于英文：** 类似 Cyberpunk 风格但保留粗野主义的锐利
- **数字使用等宽/表格数字 或特殊设计的粗体数字**

## 五、间距与边框

### 圆角系统

| 元素 | 圆角 | 说明 |
|------|------|------|
| UI 卡片/面板 | **0px** | 完全锐角，绝对无圆角 ← **粗野主义核心** |
| 用户头像 | 50%（圆形） | **唯一例外** — 圆形头像 |
| 通知 Badge | 50%（圆形） | 小红点通知 |
| 体力图标 | 不规则圆角 blob | 唯一的有机形状，形成视觉对比 |
| 按钮 | 0px（锐角） | 或微小的 2px，几乎不可见 |

**关键洞察：圆角的缺席是粗野主义最根本的定义性特征。** 本设计仅在无可避免的位置（人头像、通知点）使用圆形，其余所有元素严格尖锐。

### 阴影 — 零阴影哲学

```
/* 本设计不存在的 CSS */
box-shadow: none;
/* 没有 drop-shadow、没有 text-shadow、没有 glow */
```

**深度的达成方式：**
- 等角透视（3D 模型自带深度）
- 黑色底座 vs 白色顶面的对比（色块本身创造层次）
- 白色面板放在黑色底座上 → 视觉"浮起" → 但无任何投影

### 间距尺度

| 间距 | 值 | 用途 |
|------|-----|------|
| XS | 4-6px | UI 图标组内间距 |
| S | 8-12px | 左侧卡片间距 |
| M | 16-20px | 边缘留白 |
| L | 24-32px | 中央 3D 舞台呼吸空间 |
| 构造线 | 等角网格间距 | 3D 模型内的工程制图节奏 |

### 边缘布局

元素紧密贴附于屏幕边缘（顶部、左侧、右下角），而中央 3D 结构享有**大量负空间（呼吸感）**。这种"边缘紧凑 + 中央透气"的对比是本布局的核心张力。

## 六、标志性视觉元素

### 1. 等角 3D 建筑模型（Isometric Map）

**这是整个设计的灵魂。** 不是传统的 2D 内容区域，而是一个旋转 45° 俯视角的 3D 建筑：
- 白色几何面板 + 黑色结构基础
- 多层、层叠式建筑群
- 线框叠加 — 可见的辅助线和构造节点
- 类似在 Blender、SketchUp 或 AutoCAD 中查看模型
- 浮空几何原始体（球、立方体群）散落四周

### 2. 工程制图元素

- **辅助线（Guide Lines）：** 从建筑节点延伸的细白线，水平和等角方向
- **构造节点（Construction Nodes）：** 线交叉处的小圆球
- **网格覆盖层（Grid Overlay）：** 浅灰色网格线覆盖红色背景，类似工程制图的坐标纸
- **浮空原始体：** 独立的立方体/球体/锥体，仿佛建模软件视口中的未放置对象

### 3. 警示条纹（Hazard Stripes）

黑/白对角条纹（"candy cane" / "caution tape" pattern）：
- 出现在 "Mission" 按钮上
- 出现在建筑结构的基座
- 模仿建筑工地警示带
- 工业/施工危险的视觉编码

### 4. 红色资源连线

红色直线从右下 CTA 延伸至中央建筑，可视化资源（体力/Sanity）的操作流向：
- 颜色：`#FF0000`
- 粗细：1-2px
- 风格：绝对直线（非曲线）
- 隐喻：系统内部的资源管道

### 5. Glitch / 模板文字效果

中文字符带有刻意"断裂"的切口，仿佛是：
- 模板喷漆（stencil）的镂空间隙
- 数字腐败/Glitch 的视觉表现
- 强化"受损系统"或"危机状态"的叙事

### 6. 章节浮动标识

浮在 3D 建筑上方的当前章节标签：
- "Chapter 1: Disappearance"
- ◀ ▶ 导航箭头
- 轻巧地悬浮，不遮挡建筑

### 7. 构造中的未完成感

建筑某些部分显示"剖面"或未覆盖的黑色结构，暗示：
- 持续建设/扩张
- 玩家可以添加/修改建筑
- "蓝图阶段"的不完美真实感

## 八、与 Terminal Brutalist 的深度对比

这是六种风格中与 Terminal Brutalist **基因最相似**的参考。

| 维度 | Isometric Brutalism | Terminal Brutalist (当前) | 相似度 |
|------|---------------------|--------------------------|--------|
| 圆角 | **0px 绝对锐角** | 0-4px (接近) | ★★★★★ |
| 阴影 | **绝对无阴影** | 无阴影 | ★★★★★ |
| 配色逻辑 | 严格黑-白-灰 + 单一强调色 | 黑-灰 + CSS 变量 | ★★★★☆ |
| 边框 | 无可见边框，色块分离 | 1-2px 锐利边框 | ★★★☆☆ |
| 排版 | 几何无衬线 + Glitch 效果 | Space Mono 等宽 | ★★★☆☆ |
| 工业感 | 警示条纹、制图线 | 终端/命令行隐喻 | ★★★★☆ |
| 背景 | 红色（激进） | `#161618`（保守） | ★★☆☆☆ |
| 3D 元素 | 等角 3D 核心 | 无 3D | ★☆☆☆☆ |
| 内容容器 | 非标准沉浸式环境 | 标准 2D 卡片/表格 | ★☆☆☆☆ |

### 核心差异总结

1. **背景选择：** Isometric Brutalism 使用侵略性红色 → Terminal Brutalist 使用安全的深灰
2. **空间维度：** Isometric Brutalism 是 3D 环境 → Terminal Brutalist 是 2D 平面
3. **无边框 vs 有边框：** Isometric 用色块分离 → Terminal Brutalist 用 1-2px 边框
4. **字体选择：** 几何无衬线 + Glitch → 等宽字体（Space Mono）
5. **叙事驱动 vs 功能驱动：** Isometric 有"危机管理"的故事 → Terminal Brutalist 是纯粹的工具

## 九、可借鉴元素（用于 Talos）★★★ 高优先级

这个风格是 Terminal Brutalist **进化方向的最佳参考**。以下是可直接借鉴的元素，按优先级排列：

### Tier 1 — 立即适配

1. **绝对 0px 圆角：** 将 Talos 的 `border-radius: 4px` 降为 `0px`，是最低成本的粗野主义纯度提升
2. **警示条纹图案：** 在错误状态、警告横幅、重要操作按钮上使用黑白对角条纹
3. **构造线/网格背景：** 在仪表盘背景或卡片内添加极淡的工程网格（`rgba(255,255,255,0.03)`）
4. **绝对无阴影：** 确保全局 `box-shadow: none`，当前遵守程度检查
5. **红色强调色的精确使用：** 仅用于通知 Badge、关键连线、错误状态

### Tier 2 — 中期探索

6. **等角 2.5D 数据可视化：** 将平面图表升级为等角透视的 3D 柱状图/建筑块 — 这是与所有其他 ERP 产品的核心区分点
7. **构造节点图标系统：** 开发一套"制图节点"风格的图标（小球 + 短线交叉），替代传统 icon font
8. **Glitch/模板文字效果：** 在特定场景（错误页、维护页、品牌标题）使用文字镂空效果
9. **红色连线隐喻：** 在数据流/关系可视化中使用彩色连线（设备 → 订单 → 客户）

### Tier 3 — 长期灵感

10. **全等角 3D 仓库视图：** 设备仓库使用等角建筑模型展示，替代传统列表
11. **"建造中"的渐进感：** 未完成/加载中的模块显示为"线框+构造线"的蓝图状态
12. **章节/阶段浮动标识：** 操作流程（租赁周期）的阶段指示器浮在主内容上方

## 十、设计系统映射表

将 Isometric Brutalism 的设计语言映射到 Talos 的 CSS 自定义属性体系：

| Terminal Brutalist 变量 | 新建议值 | 改动程度 |
|---|---|---|
| `--bg-base` | `#161618`（保持不变） | 无 |
| `--border-radius` | `0px`（从 4px 降低） | 小 |
| `--border-width` | `2px`（保持） | 无 |
| `--text-primary` | `#FFFFFF`（保持） | 无 |

## 十一、警告与边界

**不应照搬的：**
- **红色全局背景：** 不适合 ERP 的日常使用，会引起视觉疲劳和焦虑
- **3D 环境替代所有 2D UI：** 不适合数据密度高的管理场景
- **Glitch 文字破坏可读性：** 在数据敏感的场景中不可接受
- **完全放弃无边框：** 在复杂表单和表格中，边框仍有功能性价值

**应保留的原则：**
- 锐角 0px、零阴影、极限制色、工业警示语言、构造隐喻
