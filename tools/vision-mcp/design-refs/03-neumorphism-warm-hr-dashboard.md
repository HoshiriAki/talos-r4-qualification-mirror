## 一、风格定义

### 主风格：Neumorphism（新拟物）+ Soft UI 混合

Neumorphism 的标志性特征是通过柔和的内外阴影在元素表面制造"浮起"或"沉入"的效果。本设计在传统 Neumorphism 基础上做了现代改良，避免了极端浮雕感，加入了更多 Flat 和 Soft UI 的元素。

### 子风格特征

| 子风格 | 权重 | 表现 |
|--------|------|------|
| **暖色调单色系** | ★★★★★ | 米色/奶油色主导，替代传统蓝白医疗感 |
| **Neumorphic 光影** | ★★★★☆ | 元素通过内外阴影制造"软浮动"层次 |
| **超大圆角** | ★★★★★ | 所有元素几乎全圆角（20-24px 卡片，Pill 按钮） |
| **个人信息核心** | ★★★★★ | 大尺寸头像 + 个人资料卡成为视觉重心 |
| **数据可视化多样化** | ★★★★☆ | 柱状图、环形进度、时间线三种图表共存 |
| **深色对比卡** | ★★★☆☆ | 单块深色卡片在浅色界面中形成焦点 |
| **折叠面板（Accordion）** | ★★★☆☆ | 左侧个人信息下方的可展开区块 |

### 整体情绪

**专业、冷静、有组织、精致。** 暖米色调让软件显得可亲近且"有人味"，远离传统企业软件的冷淡感。氛围轻盈透气，优先考虑可读性和数据可视化，不压追用户。属于高端、现代的生产力工具。

### 细节：Header

- **左：** 品牌 Logo（"Crextio"），Pill 形状按钮包裹
- **中：** 8 个文字导航链接水平排列（Dashboard, People, Hiring, Devices, Apps, Salary, Calendar, Reviews）
- **右：** 设置齿轮 ⚙️ → 通知铃铛 🔔（红色 Badge）→ 用户头像
- **高度：** ~60px

### 细节：Sub-Header

- **上排：** 大标题 "Welcome in, Nixtio"（Bold, ~28px）
- **下排：** 4 个统计指标卡片 (Interviews: 24, Hired: 16, Project time: 02:35, Output: 78%)
- **下排最右：** 3 个汇总数字 (Employee: 256, Hirings: 34, Projects: 128)
- **Hired 指标：** 使用金黄色（`#E6C552`）高亮，形成色彩锚点

### 细节：左列（~30%）— 个人中心

#### 用户资料卡（大）
- **头像：** 大尺寸高质量肖像照（"Lora Piterson"），带软阴影，略微重叠于卡片背景网格之上
- **姓名 + 职位：** 头像下方
- **统计数据：** 可能包含工作时长、项目数等个人指标

#### 折叠面板组（Accordion）
- Pension（养老金）
- Devices（设备）
- Compensation（薪酬）
- Benefits（福利）
- 每个面板可展开/折叠，带展开箭头图标
- 使用细微的 Neumorphic 内凹效果表示折叠区域

### 细节：中列（~35%）— 工作统计

#### "Progress" 进度柱状图
- 垂直柱状图，柱体为圆角胶囊形
- **高亮柱（周五）：** 顶部浮出标签 "5h 25m"
- 水平轴：星期一到六
- 每个柱体颜色可能一致或仅有高亮柱使用强调色

#### "Time tracker" 时间追踪器
- **核心：** 大圆形组件
- **外环：** 虚线环（轨道）+ 实线金黄色弧（已完成进度）
- **中心：** 大号时间数字 "02:35"
- **下方：** 播放/暂停/重置按钮（Pill 形状，小尺寸）

#### 日历 / 日程
- **水平时间线视图：** 周一至周六横向排列
- **事件卡片：**
  - "Weekly Team Sync"（黑色 Pill）
  - "Onboarding Session"（白色 Pill）
- **时间标签：** 每个事件旁边显示时间
- **当前日期：** 可能用强调色标识

### 细节：右列（~35%）— 入职管理

#### "Onboarding" 入职状态
- 多个入职进度条，每个显示：
  - 姓名
  - 进度百分比
  - 水平进度条（圆角，金黄色填充）

#### "Onboarding Task" 入职任务清单
- **深色模式卡片：** 炭色背景（`#2C2C2C`），是整页唯一的高对比暗色元素
- 任务清单项，每行包括：
  - 复选框（空心圆 ○ / 完成 ✓）
  - 任务名称
  - 状态标签
- **底部：** "Task" 操作按钮（金黄色 `#E6C552`）

## 三、色彩体系

### 角色色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#F5F5F0` | 整页底色，暖米白 |
| 卡片表面 | `#FFFFFF` | 标准白色卡片 |
| 次卡片 | `#F9F9F4` | 稍暖的奶油白卡片 |
| 主强调色 | `#E6C552`（芥末金/暖黄） | "Hired" 高亮、时间环进度、Task 按钮 |
| 深色对比卡 | `#2C2C2C`（炭色） | "Onboarding Task" 卡片背景 |
| 主文字 | `#1A1A1A` | 标题、重要文字 |
| 次文字 | `#666666` | 标签、说明 |
| 辅助文字 | `#999999` | 次要元数据 |

### 色彩原则

- **暖色单色系基底：** 白-米-奶油渐变，替代传统蓝-白企业 UI
- **单一强调色：** 金黄色 `#E6C552` 作为唯一色彩亮点，克制使用
- **无冷色：** 没有蓝色、绿色等冷色调，独树一帜
- **深色卡仅一块：** 整页仅一个深色面板，最大化其视觉冲击力
- **阴影暖色化：** Neumorphic 投影可能带微暖色调（而非纯灰）

### Neumorphic 光影规则

```
/* 凸起元素（浮出背景） */
box-shadow:
  8px 8px 16px rgba(0, 0, 0, 0.06),    /* 右下暗影 */
  -4px -4px 12px rgba(255, 255, 255, 0.8); /* 左上亮影 */

/* 凹陷元素（压入背景） */
box-shadow:
  inset 3px 3px 8px rgba(0, 0, 0, 0.06),
  inset -3px -3px 8px rgba(255, 255, 255, 0.8);
```

## 四、字体排版

### 字体家族

**首选：** Inter / Plus Jakarta Sans / Poppins  
**特征：** 现代几何无衬线，高可读性，数字等宽

### 字重阶梯

| 层级 | 字重 | 大小 | 用途 |
|------|------|------|------|
| L1 | Bold 700 | 28px | 页面欢迎语（"Welcome in, Nixtio"） |
| L2 | Semi-Bold 600 | 18-20px | 区域标题（"Progress", "Time tracker"） |
| L3 | Medium 500 | 15-16px | 卡片子标题、折叠面板标签 |
| L4 | Regular/Medium 400-500 | 13-14px | 正文、标签 |
| L5 | Bold 700 | ~24px | 大型数字（"02:35"、"256"） |

### 排版原则

- **数字加粗放大：** 统计指标（24, 16, 02:35）使用 Bold + 大字号
- **表格数字对齐：** 所有数值使用 tabular-nums，保证列对齐
- **折叠面板紧凑排列：** 行高较低（~1.3），容纳更多选项
- **大小写规范：** 标题使用首字母大写（Title Case），标签使用全大写可选

## 五、间距与边框

### 圆角系统（极度圆角化）

| 元素 | 圆角 | 说明 |
|------|------|------|
| 内容卡片 | 20-24px | 极高圆角，标志性特征 |
| 按钮 | 50%（完全 Pill） | 操作按钮全圆角 |
| 图表组件 | 10-15px | 柱状图柱体顶部、进度环 |
| 输入框 | 12-16px | 搜索/表单输入 |
| 头像 | 50%（圆形） | 用户头像 |

### Neumorphic 阴影

阴影是 Neumorphism 的核心。本设计使用较浅的阴影值：
```
/* 标准浮起卡片 */
box-shadow:
  10px 10px 20px #D9D9D4,
  -10px -10px 20px #FFFFFF;

/* 按钮按下状态 */
box-shadow:
  inset 5px 5px 10px #D9D9D4,
  inset -5px -5px 10px #FFFFFF;
```

### 间距尺度

| 间距 | 值 | 用途 |
|------|-----|------|
| XS | 8px | 紧密关联项 |
| S | 12px | 折叠面板内部、标签间距 |
| M | 16-20px | 卡片内边距、网格间距 |
| L | 24-30px | 区域间距、卡片内部 padding |
| XL | 36px+ | 大区块间隔 |

### 分割线

**无可见硬边框。** 元素分离完全依靠：
- Neumorphic 阴影的浮起效果
- 背景色差异（`#F5F5F0` vs `#FFFFFF` vs `#F9F9F4`）
- 充裕的留白

## 六、标志性视觉元素

### 1. 大尺寸个人头像

"Lora Piterson" 的肖像照是页面的视觉重心。高质量摄影、柔和阴影、略微超出卡片边界的"破框"效果，赋予人文感。

### 2. 圆角胶囊柱状图

垂直柱体的顶部完全圆角化（capsule 形状），而非传统的平顶柱。悬停时浮出数值标签。

### 3. 环形时间追踪器

Neumorphic 风格的大圆环：
- 外虚线轨道
- 金黄色实线弧表示进度
- 中心大字时间读数
- 底部小 Pill 控制按钮

### 4. 水平时间线日历

Mon-Sat 横向排列，事件以彩色 Pill 叠加在日期下方：
- 黑色 Pill = 团队会议
- 白色 Pill = 培训课程
- 金黄色高亮 = 当前日期

### 5. 折叠面板组（Accordion）

个人信息下方的 4 个可折叠区块，展开箭头 + Neumorphic 的内凹效果表示折叠/展开状态。

### 6. 深色任务清单卡

唯一的高对比暗色面板（`#2C2C2C`），白色文字 + 金黄色操作按钮，在浅色海洋中形成强烈焦点。

### 7. 统计指标条

Sub-header 中的水平统计条：4 个小指标（带图标 + 数值）+ 3 个大汇总数。金黄色用于高亮"当前活跃"指标。

## 七、适用场景

- **HR / 人事管理系统**
- **个人工作台 / 仪表盘**

## 八、与 Terminal Brutalist 的差异

| 维度 | Neumorphism Warm | Terminal Brutalist |
|------|-----------------|-------------------|
| 圆角 | 极大 (20-24px, Pill) | 极小 (0-4px) |
| 阴影 | Neumorphic 双面阴影 | 无阴影 |
| 边框 | 无可见边框 | 1-2px 锐利边框 |
| 色彩 | 暖米白 + 金黄 | 暗黑 + 高对比 |
| 字体 | 现代无衬线 | 等宽为主 |
| 按钮 | 完全 Pill 圆角 | 锐角矩形 |
| 情绪 | 温暖、精致、人文 | 硬核、极客、原始 |
| 材质感 | 软浮雕、Neumorphic | 平面、印刷品感 |

## 九、可借鉴元素（用于 Talos）

1. **折叠面板组** — 在侧边栏或设置页使用 Accordion 组织相关信息
2. **水平时间线日历** — 出租日程/预约查看的替代布局
3. **环形进度组件** — 设备归还状态、订单完成度的可视化
4. **统计指标条** — 仪表盘顶部的汇总指标（今日订单、在租设备、待归还等）
5. **深色焦点卡** — 在暗色 Terminal Brutalist 界面中反转为"亮色焦点卡"
6. **大数字 + 小标签层级** — KPI 数值的排版模式
7. **Neumorphic 光影逻辑** — 虽然 Terminal Brutalist 不用阴影，但"凸起/凹陷"的层次思维可以通过边框粗细、颜色深浅来表达
