## 一、风格定义

### 主风格：Cyberpunk 工业 HUD

将科幻电影中的 HUD（抬头显示器）和工业控制面板美学引入 UI 设计。深黑背景 + 霓虹橙强调色，搭配拟物化旋钮和仪表，模拟物理硬件控制台的感觉。这是五种风格中视觉冲击力最强的一种。

### 子风格特征

| 子风格 | 权重 | 表现 |
|--------|------|------|
| **暗黑模式原生** | ★★★★★ | 全程深黑/炭色背景，不是"暗色主题"，而是"暗黑即常态" |
| **霓虹强调色** | ★★★★★ | 电光橙单一强调色，高饱和度，模拟霓虹灯光 |
| **Skeuomorphism（拟物）** | ★★★★★ | 旋钮、仪表、3D 硬件渲染模拟真实物理设备 |
| **Sankey 能量流图** | ★★★★☆ | 中央大型桑基图展示能量/数据流向 |
| **全大写排版** | ★★★★☆ | 几乎所有文本使用全大写，营造工业/军事控制台感 |
| **仪表与量表** | ★★★★☆ | 半圆仪表、圆形进度环、模拟物理指针 |
| **3D 产品渲染** | ★★★☆☆ | 高保真 3D 硬件渲染融入界面 |

### 整体情绪

**严肃、强大、高效。** 传达控制高压机器/未来发电机的感觉。黑 + 霓虹橙暗示能量与热量。界面被设计成未来发电机或电动车充电器的控制面板，将数据可见性和"酷感"置于传统极简网页设计之上。

## 二、布局结构

### 顶层框架

```
┌──────────────────────────────────────────────────────────────┐
│                         HEADER                               │
│  [PHOENIX]  |  DASHBOARD  STATISTICS  SUPPORT  SETTINGS  |  ⊞ 👤│
├──────────────────────────────────────────────────────────────┤
│                              │                               │
│      左列 (~65%)             │       右列 (~35%)              │
│                              │                               │
│  ┌───────────────────────┐   │  ┌───────────────────────┐   │
│  │                       │   │  │                       │   │
│  │    ENERGY FLOW        │   │  │     ZEUS-X            │   │
│  │    (桑基能量流图)       │   │  │     (3D 产品渲染)     │   │
│  │                       │   │  │                       │   │
│  └───────────────────────┘   │  │  [POWER 旋钮]         │   │
│                              │  └───────────────────────┘   │
│  ┌─────────┬─────────┬─────┐ │                               │
│  │ DETAILS │ FLASH   │ VOLT│ │  ┌───────────────────────┐   │
│  │ 数据面板  │ MODE    │ DISP│ │  │  CHARGING MODE        │   │
│  │         │ CABLE   │     │ │  │  (半圆充电仪表)         │   │
│  │         │ 充电线图  │ 电压 │ │  │                       │   │
│  └─────────┴─────────┴─────┘ │  └───────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```

### 细节：Header

- **左：** "PHOENIX" Logo，全大写，宽字间距，电影级科技感
- **中：** 4 个导航链接，全大写：DASHBOARD | STATISTICS | SUPPORT | SETTINGS
- **右：** 网格视图图标 + 用户头像（圆形）
- **高度：** ~56px
- **当前页标识：** 导航项下划线或色彩变化（橙色高亮）

### 细节：ENERGY FLOW（桑基图 — 左列主区域）

- **图表类型：** Sankey Diagram（桑基能量流图）
- **视觉特征：**
  - 粗曲线带从右向左流动
  - 每条带的宽度与流量成正比
  - 不透明度变化表示负荷
  - 橙色 = 活跃/高负载，灰色 = 低负载/不活跃
- **背景：** 深色面板，可能带微网格线
- **数据标签：** 关键节点标注数值（如 "38 KWH"）

### 细节：底部三面板（左列下方，三等分）

#### DETAILS（数据详情）
- 垂直列表布局
- 参数名 + 数值对
- 细分隔线（1px 暗灰）

#### FLASH MODE CABLE（充电线图示）
- 图形化充电线表示
- 磁性耦合器图示
- 连接状态指示

#### VOLT DISPLAY（电压显示）
- 大数字电压读数（如 "23.8"）
- 单位标识
- 可能包含微型趋势指示

### 细节：ZEUS-X（右列上方）

- **3D 产品渲染：** 高保真发电机渲染图，含环境照明和烟雾/光效
- **POWER 旋钮：** 真实物理旋钮的拟物渲染
  - 金属质感纹理
  - 边缘滚花（knurling）
  - 发光电源图标
  - 旋钮角度指示当前位置

### 细节：CHARGING MODE（右列下方）

- **半圆仪表（Semi-circular Gauge）：**
  - 发光指针
  - 渐变边缘（橙 → 灰）
  - 刻度标记
  - 中心数值读数
- **背景：** 深色卡片面板

## 三、色彩体系

### 角色色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#0D0D0F` | 最深底色 |
| 次背景 | `#141418` | 卡片/面板背景 |
| 卡片表面 | `#1A1A1E` | 浮起面板 |
| 主霓虹强调 | `#FF5722` → `#FF6D00` | 活跃状态、能量流高亮、旋钮、切换开关 |
| 文字-主要 | `#FFFFFF` | 标题、重要数值 |
| 文字-次要 | `#B0B0B0` | 标签、说明 |
| 分割线 | `#333333` | 面板内细分隔 |
| 非活跃 | 冷灰蓝 | 桑基图中不活跃的流线、未选中状态 |
| 警示渐变 | 红橙渐变 | 电池仪表渐变边框 |

### 色彩原则

- **9:1 暗亮比：** 90% 深色（`#0D0D0F` ∼ `#1A1A1E`）+ 10% 霓虹橙
- **单一霓虹色：** 所有强调全部由电光橙及其渐变完成，无第二强调色
- **橙色的三种用法：**
  1. **活跃/开启态：** 全亮橙（`#FF6D00`）
  2. **数据高亮：** 桑基图活跃流线
  3. **交互元素：** 旋钮外圈、切换开关
- **灰度过渡：** 在深黑 → 暗灰 → 中灰之间建立 4-5 级灰阶
- **无白色卡片：** 全程无纯白表面

## 四、字体排版

### 字体家族

**首选：** Eurostile / Michroma / Orbitron / Montserrat  
**特征：** 几何感极强的无衬线体，宽字距，科技/军事风格

### 字重阶梯

| 层级 | 字重 | 大小 | 用途 |
|------|------|------|------|
| L1 | Bold 700-900 | 28-36px | 产品名（"ZEUS-X"）、Logo（"PHOENIX"） |
| L2 | Bold/Semi-Bold | 18-22px | 面板标题 |
| L3 | Medium 500 | 14-16px | 导航项、子标签 |
| L4 | Regular 400 | 12-14px | 详细参数标签 |
| L5 | Bold 700 | 24-32px | 大型数据读数（"38 KWH", "23.8"） |

### 排版原则

- **全大写主导：** 导航、标题、标签几乎全部使用全大写
- **宽字距（Tracking）：** 标题级别增加 letter-spacing（~2-4px），营造电影级科技感
- **数字使用等宽/表格数字：** 数据读数保证对齐
- **粗字重：** 正文层级也倾向使用 Medium 而非 Regular，确保在深色背景上的可读性
- **无衬线 + 几何感：** 字体本身带有"未来感"（方正、几何、轻微科技风）

## 五、间距与边框

### 圆角系统

| 元素 | 圆角 | 说明 |
|------|------|------|
| 内容面板/卡片 | 12-16px | 中等圆角，不似 Soft UI 般极度圆润 |
| 按钮 | 8-12px | 矩形为主，微圆角 |
| 仪表/量表 | 依形状而定 | 圆形/半圆形天然全圆角 |
| 旋钮 | 50%（圆形） | 物理旋钮的拟物渲染 |

### 阴影与发光

阴影不是用于"浮起"，而是用于"发光"：
```
/* 霓虹发光效果 */
box-shadow:
  0px 0px 16px rgba(255, 87, 34, 0.4),   /* 橙色光晕 */
  0px 0px 32px rgba(255, 87, 34, 0.15);  /* 外层扩散 */

/* 面板浮起 — 暗色界面中的微弱亮度差 */
box-shadow:
  0px 2px 12px rgba(0, 0, 0, 0.5);  /* 深面板下沉 */
```

### 间距尺度

| 间距 | 值 | 用途 |
|------|-----|------|
| XS | 6px | 仪表内刻度间距 |
| S | 12px | 紧密关联面板间距 |
| M | 16-20px | 卡片内边距 |
| L | 24px | 面板间间距、卡片 padding |
| XL | 32px | 大区块分隔 |

### 分割线

在暗色界面中使用**细水平线**（1px, `#333333`）作为面板内分离器，也可以使用霓虹橙色线表示活跃的数据流向。

## 六、标志性视觉元素

### 1. 桑基能量流图（Sankey Diagram）

**这是整个设计最核心的差异化特征。** 粗曲线带表示能量/数据分布：
- 线的粗细 = 流量大小
- 线的颜色/亮度 = 活跃度
- 从一到多的分流结构
- 关键节点标注数值

### 2. 拟物化旋钮（Skeuomorphic Knob）

"POWER" 旋钮是高度拟物的物理控件渲染：
- 金属质感（渐变模拟金属反射）
- 滚花纹路（边缘 knurling）
- 发光电源图标（中心）
- 旋转角度指示当前位置
- 投影产生浮起感

### 3. 半圆仪表（Gauge）

"CHARGING MODE" 的半圆量表：
- 渐变边缘（橙 → 灰）
- 发光指针（从圆心出发）
- 刻度标记（沿弧线分布）
- 中心数值读数
- 类似汽车仪表盘的视觉语言

### 4. 3D 硬件产品渲染

"ZEUS-X" 发电机的高保真 3D 渲染：
- 环境光遮蔽
- 烟雾/粒子效果
- 金属材质
- 与 UI 面板融合（非孤立图片）

### 5. 充电线图示

"FLASH MODE CABLE" 中的图形化充电线：
- 线条图示风格
- 磁性耦合器细节
- 连接状态可视化

### 6. 全大写 + 宽字距标题

"PHOENIX"、"ZEUS-X"、"DASHBOARD" — 每个标题使用全大写 + 宽 letter-spacing，工业/军事风。

### 7. 霓虹发光效果

橙色元素周围带有柔和的辉光（glow），模拟霓虹灯光向外扩散的效果。

## 七、适用场景

- **IoT / 工业控制面板**
- **能源管理系统**
- **汽车 / 电动车充电桩 UI**
- **数据中心监控**
- **游戏内 HUD 界面**

## 八、与 Terminal Brutalist 的相似性和差异

**这是五种风格中与 Terminal Brutalist 最接近的一种。**

| 维度 | Cyberpunk Industrial | Terminal Brutalist |
|------|---------------------|-------------------|
| 暗黑背景 | ★★★★★ 深黑 `#0D0D0F` | ★★★★★ 深黑 `#161618` |
| 单色强调 | 霓虹橙 | 可选（因无硬性规定） |
| 圆角 | 中等 (12-16px) | 极小 (0-4px) ← **关键差异** |
| 发光/阴影 | 霓虹辉光 + 投影 | **无发光、无阴影** ← **关键差异** |
| 字体 | 几何无衬线 | **等宽字体** ← **关键差异** |
| 拟物元素 | 旋钮、仪表 | **平面化、无拟物** ← **关键差异** |
| 边框 | 无硬边框 | **1-2px 锐利边框** ← **关键差异** |
| 文本 | 全大写 + 宽字距 | 大小写混用，等宽字体自然间距 |

### 可借鉴的核心思路

- **深黑 + 单一霓虹色** 是高对比度的最优解，可直接适配
- **桑基图** 可用于设备流转可视化
- **仪表/量表** 可用于出租率、占用率展示
- **"发光" 效果** 需通过锐利边框 + 高亮色替代（不用 CSS glow，用 border-color）

## 九、可借鉴元素（用于 Talos）

1. **桑基图 — 设备流转可视化：** 展示设备从入库 → 出租 → 归还 → 检修的流向
2. **仪表组件 — 出租率/占用率：** 半圆或环形仪表展示实时占用率
3. **全大写 + 宽字距标题：** 部分适配 Terminal Brutalist 的标题层级
4. **暗黑即常态：** 与 Talos 默认暗色主题一致的思路
5. **单一霓虹强调色：** Talos 可定义单一强调色用于所有交互状态
6. **数据 + 3D 混合：** 如有设备渲染图，可与 UI 面板融合
7. **高对比数据读数：** 大字白色数值在深色背景上的冲击力

**注意：** 借鉴时应去掉霓虹发光、拟物元素和圆角，保留暗黑底 + 高对比 + 单一强调色 + 数据可视化多样化的核心思路。
