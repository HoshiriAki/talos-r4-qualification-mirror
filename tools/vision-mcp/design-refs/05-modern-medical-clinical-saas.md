## 一、风格定义

### 主风格：Clean Modernism + 3D Skeuomorphism 混合

干净、专业、高科技感的医疗 SaaS 界面。平面化的 UI 卡片与高拟真 3D 器官模型形成强烈对比，将临床数据"人性化"呈现。这是五种风格中在"科技感"和"人文感"之间取得最佳平衡的一种。

### 子风格特征

| 子风格 | 权重 | 表现 |
|--------|------|------|
| **临床清洁美学** | ★★★★★ | 白/灰基底，大面积留白，极简线条 |
| **3D Skeuomorphism 焦点** | ★★★★★ | 高保真 3D 心脏模型作为页面视觉核心 |
| **蓝色医疗强调** | ★★★★☆ | 宝蓝色作为信任和专业感的单一强调色 |
| **交互热点系统** | ★★★★☆ | 3D 模型上的白色圆点标注可交互区域 |
| **多模态数据展示** | ★★★★☆ | 迷你图表、进度环、趋势线共存在同一页面 |
| **深色医学影像卡** | ★★★☆☆ | 右下角暗色 X 光/医学扫描卡片 |
| **水平日期选择器** | ★★★☆☆ | 可滚动日期条，圆形日期按钮 |

### 整体情绪

**专业、可信赖、高科技。** 通过结合无菌/干净的界面设计与有机/详细的 3D 心脏图像，使医疗数据"人性化"。界面感觉精致且易于导航，典型的高端健康科技创业公司或现代医院管理软件。

### 细节：Header

- **左：** 品牌 Logo
- **中：** Pill 形状导航容器，内含多个导航选项，"Dashboard" 为当前活跃项（不同深浅背景色区分）
- **右：** 搜索栏（可能带 🔍 图标）+ 用户头像
- **高度：** ~60px
- **导航样式：** 单一 Pill 包裹所有选项，活跃项有微妙背景色变化（类似 iOS 分段控件）

### 细节：左区（~45%）— 3D 可视化

#### 3D 心脏模型
- **渲染质量：** 高保真、光泽半透明材质
- **颜色：** 红色/粉色渐变，模拟真实器官
- **投影：** 在白色背景上投射柔和阴影，产生"漂浮"效果
- **大小：** 占据左区约 70% 的空间

#### 交互热点（Hotspots）
- 白色圆形节点散布在 3D 心脏表面
- 每个节点标记可点击区域，用于深入分析特定部位
- 可能带有脉冲动画或微弱光晕

#### Heart Rate 弹窗卡片
- **位置：** 叠加在 3D 心脏上方/旁边
- **样式：** 宝蓝色背景（`#4A6CF7`），白色文字
- **内容：** 折线图显示 BPM 随时间变化
- **指标：** "127 ml" 等关键读数

#### 器官切换器
- **位置：** 左下角
- **样式：** 三个圆形图标横向排列
  - Brain（大脑图标）
  - Heart（心脏图标，当前选中）
  - Lungs（肺部图标）

### 细节：右区（~55%）— 数据分析

#### Patient Body Analysis（顶部横条）
- **横向跨越整个右区**
- **内容：** 4 个并列指标 (Glucose, Cholesterol 等)
  - 每个包含：标签 + 迷你柱状/折线趋势图（Sparkline）+ 当前数值
- **背景：** 白色卡片

#### Medication List（左下）
- **列表布局**
- **每行：**
  - 药物名称
  - 剂量信息
  - 时间/频次
  - 状态图标（已服用 / 待服用）

#### Schedule（右下）
- **水平日期选择器：**
  - 可横向滚动的日期列表
  - 每项为圆形按钮，显示日期数字
  - **选中项：** 纯蓝色实心圆 + 白色数字（如日期 "15"）
  - **非选中项：** 灰色描边圆 + 深色数字
- **日程事件列表：** 日期下方显示当日预约/事件

#### Issue Found 卡片（最右下或独立位置）
- **暗色医学影像卡：**
  - 黑色/深色叠加层
  - 内含 X 光或医学扫描影像
  - 白色/亮色文字标注异常发现
  - 与其余浅色界面形成强烈视觉对比

## 三、色彩体系

### 角色色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#F5F7FA` | 整页底色，极浅灰白 |
| 卡片表面 | `#FFFFFF` | 所有内容面板 |
| 主强调色 | `#4A6CF7`（宝蓝） | 活跃日期、心率卡片背景、图标、切换开关 |
| 深色对比卡 | `#000000` / 深黑 | "Issue Found" 医学影像卡片 |
| 主文字 | `#2E3131`（深炭色） | 标题、重要文字 |
| 次文字 | `#8B959E`（石板灰） | 次级标签、描述 |
| 器官模型 | 红/粉渐变 | 3D 心脏渲染（唯一暖色） |
| 健康指标 | 绿色 | 正常指标标记 |
| 图标点缀 | 黄/橙 | 药丸图标等特定符号 |

### 色彩原则

- **95% 中性 + 5% 蓝 + 1 个暖色焦点（心脏）：**
  - 白/灰/浅灰 = 界面的主调
  - 宝蓝 = 所有交互和强调
  - 红/粉 3D 模型 = 仅此一处暖色，形成不可忽视的视觉重心
- **蓝色传达信任与专业：** 医疗行业的经典选择
- **深黑仅用于医学影像：** 模拟真实 X 光片的观感

## 四、字体排版

### 字体家族

**首选：** Inter / SF Pro / Roboto  
**特征：** 干净的无衬线体，高可读性，适用于医疗数据

### 字重阶梯

| 层级 | 字重 | 大小 | 用途 |
|------|------|------|------|
| L1 | Bold 700 | 24-28px | 页面问候语（"Good Morning, Abraham"） |
| L2 | Medium 500-600 | 16-18px | 区域标题（"Patient Body Analysis"） |
| L3 | Light/Thin 300 + 大号 | 28-32px | 核心读数（"127 ml"）— Light 字重 + 大字号形成优雅对比 |
| L4 | Medium 500 | 13-14px | 列表项、标签 |
| L5 | Small Caps | 11-12px | 次级标签（"BPM", "Your Set Goal"），灰色 |

### 排版原则

- **大数字使用细字重：** "127 ml" 使用 Light/Thin 字重 + 大字号，营造高端感
- **标签使用小型大写：** "BPM"、"Your Set Goal" 等
- **层级清晰：** Bold 标题 → Medium 副标题 → Regular 正文 → Small Caps 标签
- **友好的人名问候：** "Good Morning, Abraham" 增加个性化温度

## 五、间距与边框

### 圆角系统

| 元素 | 圆角 | 说明 |
|------|------|------|
| 内容卡片 | 16-24px | 高圆角，营造柔和友好感 |
| 导航 Pill | 全圆角 | 顶部导航容器 |
| 按钮 | 8-16px | 操作按钮 |
| 日期选择器项 | 50%（圆形） | 日程中的日期圆形按钮 |
| 3D 模型热点 | 50%（圆形） | 交互热点 |

### 阴影

```
/* 标准卡片 — 微弱浮起 */
box-shadow: 0px 4px 16px rgba(0, 0, 0, 0.04);

/* 3D 模型 — 较大软阴影（漂浮效果） */
box-shadow: 0px 12px 40px rgba(0, 0, 0, 0.10);
```

### 间距尺度

| 间距 | 值 | 用途 |
|------|-----|------|
| XS | 8px | 趋势图内数据点间距 |
| S | 12px | 列表项间距 |
| M | 16-20px | 卡片内边距、网格间距 |
| L | 24px | 区域间距 |
| XL | 32px | 左右两大区之间 |

### 分割线

**极少使用可见边框。** 替代方案：
- 卡片通过投影和背景色差异区隔
- 列表项仅靠间距分离
- 区域间靠充裕的白色空间（white space）自然分隔

## 六、标志性视觉元素

### 1. 3D 器官模型 + 交互热点

**整个设计最独特的特征。** 高保真 3D 器官渲染（心脏、肺、脑）作为数据查看的"入口"：
- 半透明材质 + 光泽反射
- 白色圆形热点标记可交互区域
- 点击热点可能弹出详情卡（如 Heart Rate 卡片）

### 2. 叠加信息卡片

Heart Rate 卡片直接叠加在 3D 心脏上方，形成 UI + 3D 的混合深度层次：
- 第一层：白色背景
- 第二层：3D 心脏（投射阴影到背景）
- 第三层：蓝色信息卡（叠加在心脏上方）

### 3. 迷你趋势图（Sparklines）

"Patient Body Analysis" 中的内联迷你图表：
- 可能是微型柱状图或折线图
- 嵌入在指标卡内部
- 高度仅 ~30-40px
- 显示短期趋势（如过去 7 天）

### 4. 圆形日期选择器

水平可滚动日期条：
- 每项是独立的圆形按钮
- 选中态：纯蓝填充 + 白色数字
- 非选中态：灰色描边 + 深色数字
- 提供直观的日期导航体验

### 5. 暗色医学影像卡片

深黑背景 + X 光/医学扫描影像，模拟真实阅片体验。在浅色界面中形成高对比焦点。

### 6. Pill 导航容器

顶部导航使用单个 Pill 形状容器包裹所有导航选项，活跃项有微妙背景色变化，类似 iOS 分段控件（Segmented Control）。

### 7. 器官切换器

底部圆形图标行，用于在不同器官视图之间切换，当前选中器官有颜色或边框变化。

## 七、适用场景

- **医疗 / 健康科技 SaaS**
- **医院管理系统**
- **患者数据分析平台**
- **医学影像查看器**
- **生物科技数据可视化**

## 八、与 Terminal Brutalist 的差异

| 维度 | Modern Medical SaaS | Terminal Brutalist |
|------|-------------------|-------------------|
| 圆角 | 大圆角 (16-24px) | 极小 (0-4px) |
| 3D 元素 | 核心使用 3D 模型 | 无 3D，纯二维 |
| 阴影 | 投影 + 漂浮效果 | 无阴影 |
| 色彩基调 | 白/灰 + 蓝色 | 暗黑 + 高对比 |
| 字体 | 现代无衬线 | 等宽字体 |
| 情绪 | 临床、可信赖、高科技 | 原始、硬核、极客 |
| 交互热点 | 3D 模型上的可点击热点 | 传统 UI 控件 |
| 拟物程度 | 3D 器官高度拟物，其余平面 | 完全平面化 |

## 九、可借鉴元素（用于 Talos）

1. **叠加信息层级：** 将关键 KPI 卡片叠加在主数据视图上的做法
2. **圆形日期选择器：** 出租日程的日期导航可借鉴此模式
3. **迷你趋势图（Sparklines）：** 在设备列表/订单列表中嵌入微型趋势指示
4. **分段控件式导航：** Pill 包裹的导航选项，Talos 可锐角化适配
5. **器官切换器 ↔ 仓库/门店切换器：** 圆形图标切换不同仓库的数据视图
6. **"早安 + 用户名" 的个性化问候：** 仪表盘顶部增加人性化元素
7. **深色医学影像 ↔ 深色设备详情卡：** 在亮色区域中使用高对比暗色卡片展示焦点信息
8. **3D 模型交互 ↔ 设备 3D 预览：** 如未来有设备 3D 模型，可借鉴热点交互模式
