## 一、风格定义

### 主风格：Soft UI（软界面）

Soft UI 是 Neumorphism 的演进形态，介于纯 Flat Design 与传统 Neumorphism 之间。它用极其微弱的光影营造层次感，而非 Flat 的完全二维或 Neumorphism 的夸张浮雕感。

### 子风格特征

| 子风格 | 权重 | 表现 |
|--------|------|------|
| **卡片式布局** | ★★★★★ | 所有内容以独立卡片承载，卡片是唯一的内容容器 |
| **数据可视化优先** | ★★★★★ | 图表（柱状图、漏斗图、迷你折线图）是页面的核心视觉元素 |
| **高密度低压迫** | ★★★★☆ | 数据量大但通过留白和间距避免拥挤感 |
| **品牌色点缀** | ★★★★☆ | 大面积中性色 + 单一高饱和品牌色用于关键数据 |
| **圆角亲和** | ★★★★☆ | 大圆角（16-20px）软化数据界面的冰冷感 |

### 整体情绪

**高效、分析型、精致。** 冷静且有序，让复杂的财务/销售数据显得可控而非压迫。适合专业用户群体，在功能性与美学之间取得平衡。

## 二、布局结构

### 顶层框架：侧边栏 + 主内容区

```
┌──────────────┬──────────────────────────────────────────────┐
│              │                  HEADER                       │
│   SIDEBAR    │  (用户头像、标题、日期选择器)                   │
│              ├──────────────────────────────────────────────┤
│   ~220px     │  3-COLUMN GRID                               │
│   固定宽度    │  ┌──────────┬──────────┬──────────┐          │
│              │  │  左列     │  中列     │  右列     │          │
│   - Logo     │  │  KPI卡片  │  柱状图   │  人员绩效  │          │
│   - 全局搜索  │  │  筛选列表  │  漏斗图   │  平台分析  │          │
│   - 主导航    │  │           │           │           │          │
│   - 文件夹    │  └──────────┴──────────┴──────────┘          │
└──────────────┴──────────────────────────────────────────────┘
```

### 侧边栏（~220px）

**背景：** 纯白 `#FFFFFF`，与主内容区形成对比  
**内容层级：**
1. **品牌区：** Logo + 产品名（如 "Codename.com"），顶部固定
2. **全局搜索：** 搜索输入框或图标，紧随品牌区
3. **主导航：** 文字链接列表（Dashboard, Reports 等），当前页高亮
4. **个人文件夹：** 用户自定义的快捷入口，位于导航下方

**交互状态：**
- 当前活跃项：左侧色条或背景色变化
- 悬停项：微弱的背景灰

### 主内容区 Header

**左：** 页面标题（如 "New report"）+ 面包屑  
**右：** 用户头像组（圆形，带在线状态指示点）+ 日期范围选择器

### 三列网格（主体）

#### 左列 — KPI + 详情

- **Revenue 总览卡片：** 大字显示核心指标（如 `$528,976`），附涨跌百分比（绿色 `+7.9%`）
- **Filters / 筛选列表：** 按类别/平台细分数据，每行包含图标、名称、数值、迷你进度条
- 布局方向：从上到下堆叠

#### 中列 — 可视化图表

- **柱状图（Bar Chart）：** 垂直柱，圆角顶部，多组对比
- **漏斗图（Funnel）：** 垂直漏斗，展示转化率/流失
- 每个图表嵌入独立卡片中

#### 右列 — 人员 & 平台

- **Sales/Leads 表格：** 头像 + 姓名 + 数值，紧凑行布局
- **平台分析卡片：** 按平台（Dribbble, Instagram, Behance, Google）分组的指标，带平台图标
- **"Best Deal" 卡片：** 深色背景（`#1A1A1A`）的高对比焦点卡片，用于突出最重要信息

## 三、色彩体系

### 角色色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主画布背景 | `#F5F4F6` | 整个页面的底色，暖灰白 |
| 侧边栏背景 | `#FFFFFF` | 与主画布区分 |
| 卡片表面 | `#FFFFFF` | 所有内容卡片 |
| 主强调色 | `#D12B62` | Revenue、重要高亮、关键指标 |
| 增长/成功 | `#00D157` | 涨跌百分比正值、上升趋势 |
| 信息蓝 | `#3B82F6` | 链接、次要交互 |
| 深色对比卡 | `#1A1A1A` | "Best Deal" 类焦点卡片背景 |
| 主文字 | `#1A1A1A` | 标题、核心数据 |
| 次文字 | `#6B7280` | 标签、说明文字 |
| 辅助文字 | `#9CA3AF` | 次要数据、占位符 |

### 色彩原则

- **80/15/5 比例：** 80% 中性色（白/灰）、15% 主强调色、5% 其他点缀色
- **强调色不扩散：** 单一强调色仅在关键位置使用（KPI 数值、活跃状态），不滥用
- **深色对比卡：** 每页 1-2 块深色卡片作为视觉焦点锚点

## 四、字体排版

### 字体家族

**首选：** Inter / SF Pro / Roobert  
**特征：** 几何无衬线体，x-height 较高，数字等宽/表格数字以确保对齐

### 字重阶梯

| 层级 | 字重 | 大小 | 用途 |
|------|------|------|------|
| L1 | Bold 700-800 | ~32px | 核心 KPI 数值（如 `$528,976`） |
| L2 | Bold 700 | ~20px | 区域标题（如 "Revenue"） |
| L3 | Medium 500-600 | ~16px | 卡片标题、导航项 |
| L4 | Regular 400 | ~14px | 正文、表格数据 |
| L5 | Regular 400 | ~12px | 辅助标签、时间戳 |

### 排版原则

- **数字优先：** 核心指标使用最大字号和最粗字重，建立清晰的视觉层级
- **大写标签：** 次级标签使用小号全大写（Tracking 略宽）
- **数字等宽：** 所有数值使用表格数字（tabular-nums）以保证竖向对齐

## 五、间距与边框

### 圆角系统

| 元素 | 圆角 | 说明 |
|------|------|------|
| 内容面板/卡片 | 16-20px | 高圆角是定义性特征 |
| 按钮 | 8-12px | 小卡片内的操作元素 |
| 头像 | 50%（圆形） | 用户头像 |
| 图表元素 | 4-8px（顶部圆角） | 柱状图柱体圆顶 |
| 标签/徽章 | 全圆角 Pill | 状态标签 |

### 阴影系统

```
/* 卡片投影 — 极微弱，仅用于"浮起"效果 */
box-shadow: 0px 4px 24px rgba(0, 0, 0, 0.04);

/* 悬停投影 — 稍增强 */
box-shadow: 0px 8px 32px rgba(0, 0, 0, 0.08);
```

**关键原则：阴影极淡。** 不是 Neumorphism 的强浮雕，而是 Flat 的轻微层次。

### 间距尺度

| 间距 | 值 | 用途 |
|------|-----|------|
| XS | 8px | 紧密关联元素间距 |
| S | 12px | 卡片内小元素间距 |
| M | 16px | 网格间距、列表项间距 |
| L | 20-24px | 卡片内边距 |
| XL | 32px | 区域间距 |

### 分割线

**几乎不使用实线分割。** 替代方案：
- 间距 + 背景色差异区分区块
- 极淡的底色变化（如 `#F9F9FA` vs `#FFFFFF`）
- 仅在数据表格中使用极其微弱的 `1px solid rgba(0,0,0,0.06)` 分隔线

## 六、标志性视觉元素

### 1. 头像 + 状态指示点
圆形用户头像，右下角带在线状态圆点（绿/灰）。用于 Header 和人员列表。

### 2. 高对比焦点卡片
"Best Deal" 模式：深色（`#1A1A1A`）卡片在浅色界面中形成强烈视觉锚点，一个页面最多 1-2 块。

### 3. 平台图标标识
使用可识别品牌 Logo（Dribbble 粉色、Instagram 渐变色等）作为分类标识，增加色彩丰富度和辨识度。

### 4. 数据可视化组件库
- **柱状图：** 垂直柱、圆角顶部、悬停浮出数值
- **漏斗图：** 垂直漏斗、渐窄色块
- **迷你折线图（Sparklines）：** 嵌入表格/列表行内的小趋势图
- **彩色标签徽章：** 小圆角 Pill，用于分类标记（如 "Dribbble" 红色、"Instagram" 渐变）

### 5. 时间范围滑块
Header 右侧的拖动滑块，用于快速调整日期范围。

### 6. 涨跌指示器
绿色向上箭头 + 百分比（如 `+7.9%`），紧贴核心 KPI 数值。

## 七、适用场景

- **SaaS 分析仪表盘**（最典型）
- **销售/财务数据面板**
- **需要同时展示大量数据但保持可读性的后台**
- **B2B 专业工具界面**

## 八、与 Terminal Brutalist 的差异

| 维度 | Soft UI SaaS | Terminal Brutalist |
|------|-------------|-------------------|
| 圆角 | 大圆角 (16-20px) | 无或极小 (0-4px) |
| 阴影 | 有（极淡） | 无 |
| 边框 | 几乎无 | 1-2px 锐利边框 |
| 色彩 | 暖灰白 + 品牌色点缀 | 暗黑底 + 高对比文字 |
| 情绪 | 精致、高效、亲和 | 原始、硬核、极客 |
| 字体 | Inter/SF 等现代无衬线 | Space Mono 等宽为主 |

---

## 九、可借鉴元素（用于 Talos）

1. **卡片内容容器模式** — 可适配为 Terminal Brutalist 的直角卡片
2. **三列网格布局** — 通用仪表盘布局，与风格无关
3. **深色对比焦点卡** — 在亮色主题中已有的模式，暗色主题中可反转
4. **数据可视化组件** — 柱状图、迷你趋势图可复用的信息架构
5. **KPI 数值的排版层级** — 大字核心数据 + 小字标签的对比模式
