## 一、3D 视觉语言规范

### 1.1 渲染模式：Wireframe-on-Solid

来源：06 的 "线框叠加实体" 风格

```
        ┌──────────────────────────────────────┐
        │          WIREFRAME-ON-SOLID           │
        │                                      │
        │   几何体 = 纯色面 (bg-surface)         │
        │   边缘线 = 1px (border-base)          │
        │   构造线 = 虚线 (text-tertiary)        │
        │   节点   = 小方块 4×4px (accent)       │
        │   地面   = 网格参考面                    │
        │                                      │
        └──────────────────────────────────────┘
```

**规则：**
1. 所有 3D 面使用纯色填充，不使用渐变或纹理
2. 可见边使用 `1px border-base` 描边
3. 辅助线/构造线使用虚线
4. 关键节点使用小方块标记（非球体——保持几何语言一致）
5. 不使用任何光照/阴影/环境光遮蔽
6. 透视类型：等角投影（Isometric）或正射投影（Orthographic），不使用透视投影

### 1.2 透视类型决策

| 场景 | 投影类型 | 理由 |
|------|---------|------|
| 仓库俯瞰 | **Isometric 30°/30°** | 06 风格一致，测量可读 |
| 设备流转图 | **Isometric 30°/30°** | 数据流可视化 |
| 单设备预览 | **Orthographic 正面** + 可旋转 | 产品检视 |
| 日历/时间轴 | **Isometric 45°/45°** | 块状时间单元 |
| 数据图表 3D 版 | **Isometric 30°/30°** | 柱状图 3D 化 |

### 1.3 调色板 — 3D 专属扩展

在 07 的 6 级灰阶基础上，新增 3D 场景专用色：

```
角色              色值        用途

## 二、场景 1：仓库空间地图（Warehouse Map）

### 2.1 使用场景

**问题：** 操作员在多个仓库中管理数百台设备。当前只能通过列表 + 筛选查找设备位置。

**3D 方案：** 每个仓库渲染为等角建筑模型，设备以方块在货架上的位置显示。

### 2.2 视觉设计

```
                    俯瞰等角视图 (30°/30°)
        ┌──────────────────────────────────────────┐
        │                                          │
        │   ┌──────────────────────────────┐       │
        │   │  总仓 (Main Warehouse)        │       │
        │   │                              │       │
        │   │  ┌──┬──┬──┬──┬──┬──┬──┬──┐  │       │
        │   │  │  │  │  │  │  │  │  │  │  │  ← 货架排
        │   │  ├──┼──┼──┼──┼──┼──┼──┼──┤  │       │
        │   │  │■ │  │■ │■ │  │  │■ │  │  │  ■ = 已占用槽位
        │   │  ├──┼──┼──┼──┼──┼──┼──┼──┤  │       │
        │   │  │  │■ │  │  │■ │■ │  │■ │  │       │
        │   │  ├──┼──┼──┼──┼──┼──┼──┼──┤  │       │
        │   │  │■ │■ │  │  │■ │  │■ │  │  │       │
        │   │  └──┴──┴──┴──┴──┴──┴──┴──┘  │       │
        │   │                              │       │
        │   │  --- 仓库A区 ---             │  ← 构造线标签
        │   │                              │       │
        │   └──────────────────────────────┘       │
        │                                          │
        │   图例:  ■ 已占用  □ 空闲  ▣ 维修中       │
        │                                          │
        └──────────────────────────────────────────┘
              地面网格参考面 (24px 间距点阵)
```

### 2.3 交互

| 交互 | 效果 |
|------|------|
| **悬停货架槽位** | 边框从 `3d-edge` 变为 `3d-highlight`，浮出设备信息 tooltip |
| **点击槽位** | 选中态：槽位边框 `2px accent`，右侧面板滑出设备详情 |
| **切换仓库** | 等角相机平移到目标仓库（300ms 直线移动，无缓动） |
| **筛选状态** | 非匹配槽位降低 opacity 到 0.2，匹配槽位保持 1.0 |
| **视图切换** | 等角俯瞰 ↔ 正面货架立面（正交投影，切换时间 200ms） |

### 2.4 数据结构映射

```
仓库 (Building)
├── 区域 (Zone)         → 建筑的一层/一翼
│   ├── 货架排 (Aisle)   → 一排矩形块
│   │   ├── 货架列 (Rack)→ 单个矩形块
│   │   │   ├── 槽位 (Slot) → 块内的小格子 (设备的最小位置单位)
│   │   │   │   ├── 设备 (Device) → 小方块，颜色表示状态
│   │   │   │   └── 空槽位 → 虚线边框空心方块
```

### 2.5 交互热点

货架槽位上的设备方块 = **信息热点**（来源：05 的 3D 心脏白色节点）

```
  ┌──────────────┐
  │              │
  │   ┌────┐     │  ← 悬停时:
  │   │ ■  │     │    边框: 2px #FFFFFF
  │   └────┘     │    浮出标签: "SN-001"
  │              │               "Pocket 3"
  │              │               "在租 · 张三"
  └──────────────┘
```

## 三、场景 2：设备流转桑基图（Device Flow Sankey）

### 3.1 使用场景

**问题：** 管理者需要理解设备在租赁周期中的分布和流转瓶颈。

**3D 方案：** 等角桑基图，设备从一阶段"流动"到下一阶段，阶段用建筑块表示，流向用厚带状连接。

### 3.2 视觉设计

```
                    等角设备流转视图
    ┌──────────────────────────────────────────────────────┐
    │                                                      │
    │         入库             出租            归还           │
    │     ┌─────────┐     ┌─────────┐     ┌─────────┐     │
    │     │ ████████│     │ ████████│     │ ████████│     │
    │     │ ████████│────→│ ████████│────→│ ████████│     │
    │     │ ████████│     │ ████████│     │ ████████│     │
    │     │ ██ 45 ██│     │ ██ 38 ██│     │ ██ 32 ██│     │
    │     └─────────┘     └─────────┘     └─────────┘     │
    │                         │                            │
    │                         │  3 台逾期                   │
    │                         ↓                            │
    │                    ┌ ─ ─ ─ ─ ─ ┐                     │
    │                    │ ╲╲  逾  ╲╲│ ← 逾期用警示条纹     │
    │                    │  ╲╲  期  ╲│                     │
    │                    └ ─ ─ ─ ─ ─ ┘                     │
    │                         │                            │
    │                    ┌─────────┐                       │
    │                    │  检修    │                       │
    │                    │  ██ 1 ██│                       │
    │                    └─────────┘                       │
    │                                                      │
    └──────────────────────────────────────────────────────┘
```

### 3.3 阶段块规格

| 阶段 | 块颜色 | 边框 | 说明 |
|------|--------|------|------|
| **入库/空闲** | `#1A1A1E` | `1px #2A2A2E` | 等待出租 |
| **出租中** | `#3D1816` (accent 暗化) | `1px #FF453A` | 正在使用 |
| **归还中** | `#1A1A1E` | `1px #FF9F0A` | 运输/确认中 |
| **逾期/异常** | 警示条纹 | `2px #FF453A` | 需要处理 |
| **检修中** | `#1A1A1E` | `1px #FF9F0A` | 维修 |
| **报废** | `#1A1A1E` | `1px #3D3D42` | 生命周期结束 |

### 3.4 交互

- **悬停阶段块：** 块边框高亮，显示该阶段的设备列表 mini tooltip
- **点击阶段块：** 相机推近，块展开显示内部设备列表
- **悬停连接带：** 带高亮，显示流量数值 "今日 5 台 →"
- **时间切换：** 滑块控制时间范围，流转数据动态更新

### 4.3 渲染规格

| 属性 | 值 |
|------|-----|

| 缩放 | 固定三档：全局 / 中景 / 特写 |
| 背景 | 透明或 `#0D0D0F`，带工程网格参考面 |
| 标注线 | 虚线从零件延伸至标签文字 |

## 六、场景 5：等角数据仪表盘（Isometric Dashboard）

### 6.1 使用场景

**问题：** 标准 2D 仪表盘无法直观展示空间关系和多维度对比。

**3D 方案：** 将仪表盘的核心 KPI 以等角几何体的形式组织在一个虚拟"桌面上"。

### 6.2 视觉设计

```
                 等角仪表盘桌面
    ┌──────────────────────────────────────────────────────┐
    │                                                      │
    │   ┌────────┐    ┌────────┐    ┌────────┐            │
    │   │▐█▌▐█▌▐█▌│    │  ┌──┐ │    │  ╭──╮  │            │
    │   │▐█▌▐█▌▐█▌│    │  │85│ │    │ ╱    ╲ │            │
    │   │▐█▌▐█▌▐█▌│    │  │% │ │    ││ 今日 ││            │
    │   │ 收入趋势 │    │  └──┘ │    ││ ¥8.9K││            │
    │   │ (柱状图) │    │ 占用率 │    │ ╲    ╱ │            │
    │   └────────┘    │ (仪表) │    │  ╰──╯  │            │
    │                  └────────┘    │ 收入环  │            │
    │   ┌──────────────┐             └────────┘            │
    │   │ ████░░░░░░░ │                                    │
    │   │ ████░░░░░░░ │  ┌───────────────┐                │
    │   │ 设备状态分布  │  │ 订单 设备 客户  │ ← 数据看板    │
    │   │ (堆叠条)     │  └───────────────┘                │
    │   └──────────────┘                                    │
    │                                                      │
    │   ═══════════════════════════════════  ← 地面参考面    │
    │                                                      │
    └──────────────────────────────────────────────────────┘
```

### 6.3 布局逻辑

桌面被划分为多个"展台"（pedestal）：
- 每个展台 = 一个 BG-Surface 色的矩形台座
- 展台上立着一个数据可视化组件
- 展台之间有 `1px border-base` 的分隔线
- 最重要的 KPI 展台升高（台座更高），次要的降低

## 七、场景 6：租赁周期时间线（Rental Lifecycle Timeline）

### 7.1 使用场景

**问题：** 管理和追踪单个设备的完整租赁历史。

**3D 方案：** 等角 Z 轴时间线——设备沿 Z 轴（深度）穿越时间，每个租赁事件是一个块。

### 7.2 视觉设计

```
            设备生命周期时间线 (等角, Z轴 = 时间)
    ┌──────────────────────────────────────────────────────┐
    │                                                      │

## 八、场景 7：仓库容量 3D 热力图（Warehouse Capacity Heatmap）

### 8.1 使用场景

**问题：** 多仓库场景下快速识别哪个仓库已满、哪个有余量。

**3D 方案：** 每个仓库是一个等角立方体，填充高度 = 占用率。

## 九、技术实现路径

### 9.1 推荐技术栈

| 方案 | 适用场景 | 优势 | 劣势 |
|------|---------|------|------|
| **Three.js + CSS3DRenderer** | 所有场景 | 成熟生态、可混合 DOM 标注 | Bundle 体积 ~120KB |
| **CSS 3D Transforms** | 简单场景（仓库地图、容量对比） | 零依赖、DOM 原生可访问 | 复杂模型难实现 |
| **SVG Isometric** | 静态图表（日历山、容量对比） | 矢量清晰、小体积 | 无真正 3D 交互 |
| **WebGL + 自定义 shader** | 需要极致性能的大数据量 | 可定制 | 开发成本高 |

**推荐：Three.js + CSS3DRenderer**

- Three.js 处理 3D 几何体和渲染
- CSS3DRenderer 允许在 3D 场景中嵌入 HTML/CSS 标注
- 渲染风格通过 `MeshBasicMaterial`（无光照）实现 Brutalist 平面着色
- 边线通过 `EdgesGeometry` + `LineBasicMaterial` 实现

### 9.2 渲染配置（Three.js 示例）

```javascript
// Brutalist 无光照渲染配置
const scene = new THREE.Scene();
scene.background = new THREE.Color('#0D0D0F');

// 所有材质使用 MeshBasicMaterial（纯色，无光照）
const faceMaterial = new THREE.MeshBasicMaterial({
  color: '#1A1A1E',
  side: THREE.FrontSide,
});

// 边线自动生成
const edges = new THREE.EdgesGeometry(geometry);
const lineMaterial = new THREE.LineBasicMaterial({
  color: '#2A2A2E',
  linewidth: 1,  // 注意: WebGL 限制 linewidth = 1
});

// 等角相机设置
const camera = new THREE.OrthographicCamera(/* ... */);
camera.position.set(10, 10, 10); // 30°/30° 等角
camera.lookAt(0, 0, 0);

// 构造线（虚线辅助线）
const guideMaterial = new THREE.LineDashedMaterial({
  color: '#3D3D42',
  dashSize: 0.5,
  gapSize: 0.25,
});

// 地面网格
const gridHelper = new THREE.GridHelper(20, 20, '#2A2A2E', '#141418');
```

### 9.3 响应式策略

| 断点 | 3D 场景行为 |
|------|------------|
| ≥1280px | 完整 3D 等角视图，可旋转 |
| 768-1279px | 降级为固定视角，无旋转 |
| <768px | 降级为 2D 等角 SVG 静态图 + 数据叠加 |

## 十、渐进式实施路线
